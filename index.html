EMBEDDED HARDWARE & SENSORS

Core Technology & Hardware Stack.

Engineered with high-speed microcontrollers, precision servo actuators, optical intelligence, and low-noise power regulation.

MICROCONTROLLER

ESP32 Core Module

Dual-core processing hub executing real-time sensor polling, Wi-Fi telemetry, and PWM motor coordination.

VISION SYSTEM

ESP32-CAM (AI Vision)

OV2640 optical sensor capturing incoming waste images for localized inference and classification.

FIRMWARE

C++ / Embedded Code

Optimized low-latency C++ firmware architecture for hardware-level interrupts, timers, and telemetry streaming.

POWER REGULATION

LM2596 Buck Converter

Steps down high-capacity battery voltages to a steady, regulated 5V rail for jitter-free servo operation.

ACTUATION SYSTEM

Servo 180° & 360°

180° servo controls chute tilt segregation, while 360° continuous servos drive automated intake conveyors.

NAVIGATION & SENSING

IR Line Sensors

Infrared line follower sensor arrays providing line tracking for autonomous rover navigation and obstacle avoidance.
